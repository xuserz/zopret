# UFW + BBR Setup for Remnawave Node

Этот скрипт автоматически настраивает базовый файрвол (UFW) и включает алгоритм ускорения сети BBR на сервере, подготовленном для работы Remnawave Node.

Он разработан для серверов под управлением **Debian/Ubuntu** и автоматизирует процесс, описанный в документации Remnawave и сообщества.

---

## 🚀 Быстрая установка

Выполните эту команду на вашем сервере-ноде от имени **root**:

```bash
bash <(curl -s https://raw.githubusercontent.com/xuserz/zopret/refs/heads/main/ufw-bbr-setup.sh)
```

Скрипт запросит:

1. **IP-адрес вашей панели управления Remnawave**
2. **Порт для SSH** (можно нажать Enter, чтобы оставить `22` по умолчанию)
3. **Порт для API ноды** (можно нажать Enter, чтобы оставить `2222` по умолчанию)

Всё остальное скрипт сделает автоматиiquement.

---

## 📋 Назначение портов

| Порт                  | Протокол | Назначение                             | Доступ                            |
| :-------------------- | :------- | :------------------------------------- | :-------------------------------- |
| `22` (или ваш порт)   | TCP      | SSH-доступ к серверу                   | Для всех (рекомендуется изменить) |
| `80`, `443`           | TCP      | Веб-трафик                             | Для всех                          |
| `2222` (или ваш порт) | TCP      | API для связи ноды с панелью Remnawave | **Только с IP панели**            |
